    Como levar para o relógio
    • Garmin: Garmin Connect (web) → Treinamento → Percursos → Importar → envie para o relógio.
    • Apple Watch: abra o GPX no app WorkOutDoors ou Footpath e sincronize.
    • Coros: app Coros → Explorar → Rotas → Importar.
    • Polar: Polar Flow → Favoritos → Importar percurso.
    • Suunto: app Suunto → Mapa → Rotas → Importar.
    • Strava: strava.com → Rotas → Importar GPX (sincroniza com Garmin/Wahoo).
